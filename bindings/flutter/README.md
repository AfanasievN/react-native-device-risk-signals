# flutter-device-risk-signals

Planned thin Flutter binding over the standalone Android and iOS SDKs. It will translate the
shared raw-signal contract into Dart models without reimplementing native detection logic.

The product/library name is `flutter-device-risk-signals`. Because Dart package identifiers permit
underscores rather than hyphens, its pub.dev install/import coordinate will be
`flutter_device_risk_signals`. The package is not implemented or published yet.
