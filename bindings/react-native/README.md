# react-native-device-risk-signals

The active React Native binding is temporarily published from the repository root as
`react-native-device-risk-signals`. Keeping it there preserves installation, autolinking, CocoaPods,
codegen, and package exports while the native cores are extracted.

After the Android and iOS SDKs have stable public APIs, this directory will become the package
home. The npm package name and existing JavaScript API are expected to remain compatible.
