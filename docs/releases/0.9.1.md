# v0.9.1 — Android core from Maven Central

The React Native binding now resolves the published passive Android SDK
`io.github.afanasievn:android-device-risk-signals:0.1.0` from Maven Central.

- Passive core Kotlin sources are no longer bundled in npm, reducing the compressed package by
  approximately 49 KB.
- Active probes remain bundled sources; no unpublished Maven dependency is required.
- JavaScript APIs and iOS packaging are unchanged.
- Added a packaging regression test and updated CI, ecosystem metadata and documentation.

## Upgrade

```sh
npm install react-native-device-risk-signals@0.9.1
```

Ensure the host Android Gradle repositories include `mavenCentral()` and rebuild the application.
The first uncached build requires access to Maven Central. Core updates are pinned and shipped
through subsequent binding releases.

Validated with the Android demo build, native unit tests and lint, library and demo tests,
TypeScript, npm archive verification, and documentation checks.
